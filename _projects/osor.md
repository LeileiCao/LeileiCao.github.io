**OSOR** explores one-step diffusion inpainting for effect-aware object removal.
The method is designed to handle imprecise user masks and restore not only the removed
object region but also related visual effects, such as cast shadows.

The work was accepted by **ECCV 2026**.

**Research topics:** diffusion inpainting · object removal · effect-aware restoration
